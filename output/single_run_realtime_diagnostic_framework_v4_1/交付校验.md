## 2. 逻辑一致性检查

- 动态物理 Reaction deadline 统一以 `t_demand` 为原点；`t_world/t_observable/t_sample` 不得替代。
- `t_world` 与 `t_demand`、`t_observable` 与 `t_demand` 均允许由 predicate 决定先后；只普遍要求 `t_observable <= t_sample`。
- `P_OBSERVABILITY` 不通过时，若 demand/effect 端点与外部物理契约独立合格，仍允许端点式 physical miss；但禁止将总量分配或归因到 observability/sampling/software 段。
- 只有 scalar upper-bound contract 才计算 `tau - observed`；state-error envelope 与 sequence-integrity predicate 不换算成统一时间 slack。
- raw skew 可直接支持合格 Architectural Coherence contract，但 Physical Coherence 必须比较 induced state error 与安全误差包络。
- induced state error 区分实际实施的补偿与独立 reference propagation；无法从功能/模型误差中分离时保留 `TEMPORAL_AND_MODEL_ERROR_MIXED`。
- `ARCHITECTURAL/CALIBRATED/RESEARCH` 与 qualification 分列；Research threshold 不建立 C4_ARCH/C4_PHYS/guarantee。
- `D_response` 与 `D_debt` 均使用 demand-relative 墙钟速度梯形积分；sample-relative 距离保留独立字段，observed 与 model/predicted 分表。
