## 本轮关键语义决定

- \(t_{world}\) 与 \(t_{demand}\) 不被普遍强制排序：预测性需求可能领先于世界 predicate，迟滞/政策需求也可能滞后；保存有符号 \(\Delta_{world,demand}\)。
- \(t_{observable}\) 与 \(t_{demand}\) 也允许先后两种关系；分别报告 observability delay 或 lead。唯一普遍的合格采集顺序是 \(t_{observable}\le t_{sample}\)。
- `P_OBSERVABILITY` 不通过不等于世界中没有事件；它限制的是把 sample-relative 链升级为 demand-relative Reaction、以及对 demand-to-sample 时间作机制归因的资格。
- raw skew 越界可以构成合格 Architectural Coherence miss，但不能自动构成 Physical Coherence miss。
- `ARCHITECTURAL/CALIBRATED/RESEARCH` 是证据角色，不是数值大小或自动权威顺序；每个阈值仍需 scope、metric、domain、independence、lock-time 资格审计。

## 版本关系

- v3.1：单次运行 Event-Centric 时间—物理安全诊断基线。
- v4.0：增加 Multi-input Coherence、Loop-Centric、Architectural/Physical 双层契约、Effect sensitivity、Resource Interference Graph 与 Core/Extended profiles。
- v4.1：拆分四类事件时刻并加入 `P_OBSERVABILITY`；将 L 明确为 Timing Integrity；用 typed component-wise Contract Set 取代统一 \(\tau\) 向量；Physical Coherence 转为 induced state-error 主判据；阈值来源正式分为 Architectural/Calibrated/Research。
