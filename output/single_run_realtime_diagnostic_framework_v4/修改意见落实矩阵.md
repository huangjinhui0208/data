## 本版没有做出的过强扩张

- 没有把 ECRTS 的 partition theorem 解释成 root-cause theorem；Coherence 是本框架的 multi-input engineering extension。
- 没有把 loop timing 与 tracking error 的相关性直接解释成稳定性因果；需要控制 margin、验证模型或机制证据。
- 没有把 Architectural miss 解释成 Physical safety miss；只有 `C4_PHYS` 才能进入主 C5 物理预算传播。
- 没有降低 dynamic physical deadline 的 anti-leakage、独立校准和 uncertainty 资格。
- 没有用 single-run max/P99 代替 formal upper bound。

## 版本关系

- v3.1：单次运行 Event-Centric 时间—物理安全诊断基线。
- v4.0：在保持证据纪律和六证据域的基础上，加入多输入 Coherence、Loop-Centric、Architectural/Physical 双层契约、Effect sensitivity、Resource Interference Graph 与 Core/Extended profiles。
